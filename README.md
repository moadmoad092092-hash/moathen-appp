# مؤذّن | Moathen

موقع عربي متجاوب لمواقيت الصلاة، مع تطبيق Android مبني بـCapacitor وإضافة Java أصلية لجدولة الصلاة وتشغيل التسجيل من ملفات التطبيق.

## المتطلبات

- Node.js 22 وpnpm 11.25.0.
- JDK 21 وAndroid SDK Platform 36؛ يختار Gradle Build Tools المناسبة (35.0.0 في البناء المتحقق هنا) تلقائيًا.
- بيئة Android فعلية لاختبار إذن المنبهات الدقيقة والصوت عند قفل الشاشة.

## تشغيل الويب

```bash
pnpm install
pnpm dev
```

لإنتاج الموقع الثابت:

```bash
pnpm build
```

ناتج النشر موجود في `dist/`. لا يحتاج الموقع إلى خادم أو قاعدة بيانات. بعد زيارة الموقع مرة عبر الإنترنت، يخزن عامل الخدمة ملفات الواجهة والخطوط والأيقونة وملفات الأذان محليًا، وتُحفظ اختيارات المستخدم في `localStorage`. الموقع يعرض المؤقت والأذان عند بقاء الصفحة نشطة بعد أن يسمح المستخدم بالصوت؛ **المتصفح لا يضمن تشغيل الأذان تلقائيًا عند إغلاق التبويب أو تعليق الصفحة**. هذا سلوك أمني/طاقة يحدده المتصفح ونظام التشغيل.

## بناء Android

```bash
pnpm install
pnpm build
pnpm exec cap add android   # مرة واحدة فقط إذا لم يكن مجلد android موجودًا
pnpm exec cap sync android
cd android
./gradlew assembleDebug
```

يظهر APK التجريبي عادة في `android/app/build/outputs/apk/debug/app-debug.apk`. لبناء إصدار توزيع استخدم `./gradlew assembleRelease` بعد إعداد مفتاح توقيع خاص بك؛ لا يُضمّن مفتاح توقيع في المستودع. بعد أي تعديل في ملفات الويب شغّل `pnpm build` ثم `pnpm exec cap sync android`.

## إعداد أذان Android

تطلب الواجهة إذن «المنبهات والتذكيرات» قبل استخدام التنبيهات الدقيقة. عند منح الإذن تستخدم الإضافة الأصلية `AlarmManager` لإطلاق المستقبل المحلي وتشغيل خدمة وسائط أمامية. يعاد حساب الجدول عند فتح التطبيق وعند بث الإقلاع/تغيير التاريخ أو الساعة أو المنطقة الزمنية. قد تؤخر سياسات الشركة المصنّعة أو توفير الطاقة التنبيه؛ لا يمكن إثبات الاعتمادية على كل هاتف دون اختبار فعلي على مجموعة الأجهزة المستهدفة.

## الفحوصات

```bash
pnpm test
pnpm build
```

نجحت اختبارات الويب الأربعة لحساب الأوقات والتنسيق حسب المنطقة الزمنية والعد التنازلي. نجح `testDebugUnitTest` بما فيه اختبار Native لموعد الصلاة التالي والترحيل لليوم التالي، واجتاز `compileDebugAndroidTestJavaWithJavac` و`assembleDebug`. وفُكّ ملفا MP3 كاملان بواسطة FFmpeg دون أخطاء. **لم يُختبر إخراج صوت مسموع أو المنبه الدقيق مع قفل الشاشة على هاتف/محاكي**؛ لذلك يلزم اختبار الإذن والخدمة بعد تثبيت APK، ثم اختبار إعادة التشغيل وتغيير التاريخ والمنطقة الزمنية على الجهاز المستهدف.
